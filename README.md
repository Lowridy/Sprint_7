# Sprint_7
Этот репозиторий содержит автоматизированные тесты для API учебного сервиса «Яндекс Самокат» (qa-scooter.praktikum-services.ru). Тесты покрывают следующие эндпоинты:

Создание курьера (POST /courier)

Авторизация курьера (POST /courier/login)

Создание заказа (POST /orders)

Получение списка заказов (GET /orders)

Тесты написаны на Python с использованием pytest и requests, а для генерации реалистичных тестовых данных (логинов, паролей, имён) используется библиотека Faker, вместо предложенного варианта в задании генерировать логин, пароль и имя курьера. Я решил отказаться от самописного генератора и воспользовался библиотекой Faker для создания реалистичных данных:

from faker import Faker
fake = Faker("ru_RU")
login = fake.user_name()
password = fake.password(length=12, special_chars=False)
first_name = fake.first_name()

Таким образом код стал короче, а данные — более приближенными к реальным сценариям.
